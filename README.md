# ComfyUI 控制台（comfyui-console）

侧边栏独立入口的 ComfyUI 交互控制台：把本机已接入的 ComfyUI 工作流、可填参数、参考素材槽、LoRA、任务与产物集中展示，能直接在页面上改参数、传素材、运行、看产物；同时向 DSH 会话暴露一组出片工具，可被 AI 调度调用。

详细功能见 [docs/DETAIL.md](docs/DETAIL.md)。

## 结构

- `lib/index.js` — host 端：注册 `/comfy-console/*` HTTP 路由，读写 ComfyUI 工作流与产物；心跳把出片工具挂进 DSH 会话。
- `lib/client.js` — client 端：注册左侧栏入口与 React 交互 UI。
- `locale/` — 插件元数据（标题 / 描述）。
- `cordis.patch.yml` — 仅一条 insert 操作，加载本包。

## 两种使用方式

### 1. 面板手动使用（不依赖 AI 调度）

装好后在侧边栏打开控制台，手动操作：

1. 右上角「设置」填 ComfyUI 地址与 input / output 目录；
2. 导入或登记要用的工作流（API 格式 json）；
3. 选工作流、填参数、传参考素材，点「运行」；
4. 在任务 / 产物标签页看进度和结果。

### 2. AI 会话调度（可选）

插件会把 `comfyui_console_*` 一组工具挂进 DSH 会话。在自己的 agent 提示词里约定调用方式后，模型可按任务直接调用出片工具（列工作流、登记、组装、提交、查任务、取消 / 中断、查 LoRA 等）。

> 触发规则（收到图片 / 视频任务就自动调用、跑完主动汇报）写在你自己的人格提示词 / 记忆里，不在本插件内；换环境时需要在那边重新约定。IM 推送（如 QQ）需自行安装对应桥并配置桥地址。

## 连接配置

首次使用前，在面板「设置」里填三项：

- **ComfyUI 地址**：本机默认 `http://127.0.0.1:8188`；在另一台机器或容器时填 `http://IP:端口`，网络可达即可。
- **素材目录 input**：本机 ComfyUI 安装目录下的 `input` 绝对路径，参考素材上传到这里。
- **产物目录 output**：本机 ComfyUI 安装目录下的 `output` 绝对路径，运行结果从这里读取。

目录留空时素材上传和产物读取不可用。配置保存在 `~/.dsh/comfyui-canvas.json`，保存即生效，无需重启。

## 完成通知（可选开关）

设置里「跑完主动通知」默认开启：任务结束后唤醒当前会话汇报；会话不可用时兜底推送到已配置的 IM 桥。关闭后只更新台账和产物，不打扰任何人。

> 注意：工作流依赖的模型、LoRA、自定义节点需要在本机 ComfyUI 里装好；本插件只负责调度，不代为安装模型。
